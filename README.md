# Widget Studio

A canvas editor for reusable interactive widgets and portable MCP Apps exports.

Open https://thorsenk.github.io/widget-studio/ to create, organize, customize, preview and export widgets. Save and Trash use this browser’s local storage. Download editable JSON for portable backups and transfer between devices. Designs are not uploaded to a shared project server.

The widget bundle includes standalone HTML, editable JSON, a synthetic MCP Apps server, readiness report and complete integration handoff. Local widget controls work immediately. Native plugin tools need their host connection.

The included example-widget.zip contains only a synthetic QA widget. The original Mac projects and workspace records are not included.

Run locally with a static HTTP server. Keep the icons-LICENSE.txt notices with redistributed icon code.
